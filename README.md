# CLOCK(R) — Nothing OS Style Clock & Widget Suite

A dot-matrix clock and utility application built around the Nothing OS design language. Features dot-matrix typography, dark theme aesthetics, custom ringtone selections, and a dedicated landscape Dock Mode with media controls.

---

## Features

*   **Alarms**: Custom alarm creation with day repeat schedules and custom sound profiles (e.g., *Glyph Rapid*, *Retro Beats*, *Teenage Ambient*).
*   **World Clock**: Interactive dot-matrix world map displaying global locations, local times, and time zone offsets.
*   **Stopwatch & Timer**: Precise time tracking with quick-add presets (`+1m`, `+5m`, `+10m`, `+15m`) and sound notifications.
*   **Dock Mode**: Full-screen landscape nightstand view displaying system stats (battery, local weather) alongside connected media controls (Spotify/Phone Link).
*   **Widgets**: Dynamic home screen widgets including digital clock displays, weather status, upcoming alarms, and mini media controls.
*   **Customization**: 
    *   Punch-hole camera cutout adjustments (*None*, *Left Corner*, *Center Cloud*, *Right Corner*).
    *   12-Hour and 24-Hour display format toggles.
    *   Custom font support (`.ttf` / `.otf` file upload).

## Tech Stack

*   **UI Framework**: Custom Dot-Matrix rendering engine
*   **Typography**: Dot-matrix / Monospace bitmap fonts
*   **Theme**: AMOLED Dark (#000000)

---

## Customization & Fonts

You can upload custom typography via the in-app settings menu:
1. Open **Settings** ($\text{gear icon}$ top right).
2. Scroll to **App Typography & Fonts**.
3. Tap **+ Upload Custom Font (.otf / .ttf)** to load custom font files.
